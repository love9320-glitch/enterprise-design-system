## 역할 분리

| 층 | 도구 | 실행 시점 | 담당 |

| PR 게이트 | Vitest + RTL + axe (jsdom) | 모든 PR (CI `verify`) | 로직·상태·키보드 흐름·ARIA 계약·axe 위반 0 |

## 버그 수정 = 회귀 테스트 동반 (2026-08-12 사용자 지시)

버그 수정 PR에는 그 버그를 재현하는 테스트를 반드시 함께 넣는다:
1. **재현 테스트 작성** — 실패 확인(버그 증명)
2. **수정** — 테스트 통과로 수정 증명
3. **영구 보존** — 기존 스위트에 합류, 이후 모든 PR에서 재발 감시. 테스트 주석에 발생일·증상 한 줄 기록(판례화)

수정 완료 보고 시 "재현 테스트 포함" 여부를 명시한다. 테스트를 선제 확장하는 대신 실제 터진 버그가 테스트 목록이 되게 하는 방식.
